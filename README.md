# AWS Static Website Hosting

## Project Overview

This project demonstrates hosting a static portfolio website using AWS cloud services.

The website is deployed using Amazon S3 and distributed globally using Amazon CloudFront CDN.

---

## Architecture
User
|
CloudFront CDN
|
Amazon S3 Bucket
|
HTML / CSS / JavaScript Files


---

## AWS Services Used

### Amazon S3
- Created an S3 bucket for website files
- Uploaded HTML, CSS and JavaScript files
- Configured static website hosting

### Amazon CloudFront
- Created a CDN distribution
- Connected CloudFront with S3 origin
- Enabled global content delivery

### IAM
- Configured secure access permissions

## Deployment Steps

1. Created website files locally using VS Code
2. Uploaded project to GitHub
3. Created S3 bucket
4. Enabled static website hosting
5. Uploaded website files
6. Configured CloudFront distribution
7. Accessed website through CloudFront URL
